# Glossary

**Purpose:** Define common PAM 2.0 terms.  
**Audience:** End users and administrators.

| Term | Meaning |
|---|---|
| Breakglass account | A local privileged account used only for approved emergency or exceptional access |
| Confirmed | Supported explicitly by an approved or confirmed source |
| Cyolo | Session Manager providing controlled target connectivity; it does not own or rotate passwords |
| Delinea Secret Server | PAM platform owning credential lifecycle, history, governed retrieval, access policy, and audit |
| Discovery Engine | Delinea component that discovers Windows servers and local accounts |
| GPO | Windows Group Policy Object used to apply target-server configuration |
| LAPS | Windows local administrator password solution being replaced for `volvop27` |
| MFA | Multi-factor authentication required for Entra ID sign-in |
| PAM | Privileged Access Management |
| Planned | Approved control or integration not confirmed as implemented |
| Remote SAM | Windows mechanism restricting remote calls to Security Accounts Manager discovery |
| RPC | Remote Procedure Call framework used by Windows discovery and administration |
| SSO | Single sign-on through Microsoft Entra ID |
| TBC | Missing, conflicting, or not-yet-validated information |
| VCCNET | Approved Windows target environment in scope |
| VCCMFG | Approved Windows manufacturing target environment in scope |

## Source and validation status

**Confirmed:** Glossary terms derive from the approved requirements and source prompt.
