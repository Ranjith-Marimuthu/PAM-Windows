# End-User PAM 2.0 Resources

**Purpose:** Help authorized users understand and request Windows breakglass account password access.  
**Audience:** End users and incident responders.

## What PAM and breakglass access mean

Privileged Access Management (PAM) provides controlled access to sensitive Windows environments. Breakglass access is an exceptional, tightly governed option for urgent administrative work when normal permissions are unavailable or insufficient.

> [!IMPORTANT]
> Breakglass access is only for approved emergency or change activity. It is not a substitute for normal permissions.

## Before you start

Make sure you have:

1. A valid incident, request, or change reference.
2. An approved business justification.
3. An authorized target and approved task scope.
4. Access to the corporate sign-in and MFA methods.
